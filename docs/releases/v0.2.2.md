GrepMesh 0.2.2 packages the current native MCP server and ripgrep for Linux x86_64, macOS Intel, macOS Apple silicon, and Windows x86_64.

Changes since 0.2.1:
- Browse configured locations and files in the web console; stream durable cross-host search results.
- Improve persistent indexing, incremental watcher recovery, exclusions, and retained-index search fallback.
- Add OCR and optional media transcription, durable OCR retries, bounded worker pools, and resource-admitted mesh workers.
- Support CUDA OCR on Linux, CoreML OCR on Apple silicon, and bundled CPU OCR on Intel macOS (without local speech transcription).
- Preserve completed OCR outcomes across request timeouts, bound retries per file generation, and detect image formats from their bytes.

Every platform bundle is built from this tag and checked through packaged MCP initialization, version verification, and local file search. `SHA256SUMS` covers all four archives. OCR models may download on first use; PDF rendering requires `pdftoppm`. Coverage depends on configured roots, exclusions, reachable peers, and available worker resources; publication does not imply complete fleet indexing or a production rollout.
